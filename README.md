# The Impact of AI on Jobs — SPA Limitation-of-Liability Clause Builder

EMBA "Change Management and AI" assignment (HHL Leipzig Graduate School of
Management): an analysis of AI's impact on M&A transactional legal drafting,
grounded in a real law-firm practice, with a working Claude skill prototype
and its validity evaluation.

## Contents

- `2026_8_AI_Job_Impacts_Assignment_Brief.pdf`,
  `2026_8_EMBA_Assignment_AI_Job_Impacts.pdf` — the assignment brief.
- `HHL_AI_SPA_Paper_v6.docx` — the paper (main deliverable).
- `SPA_Clause_Library_EN_review.xlsx` — the firm's clause-library review
  tracker (English-wording approval status per clause; currently pending).
- `contract-clause-builder/` — the Claude skill prototype. See its own
  `README.md` for what it does and how to run it.

## Confidentiality note

The clause library renders the firm's Russian-law SPA limitation-of-liability
wording into English for this project. Every clause carries its provenance
(from an executed firm agreement, adapted, or draft/unapproved) and the
English rendering is explicitly marked pending firm approval throughout. No
client or counterparty names appear anywhere in this repository.
